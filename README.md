## 更新内容
- BOOK / QUIZシステムをゲーム本体から分離し、`books/quiz_books.js` を新設。
- 本屋に3冊のクイズ本を常設。
  - はじめてのWeb3：100G / 10問
  - Web3ステップアップ：250G / 25問
  - Web3マスター：450G / 50問
- 合計85問を収録。Web3基礎・送金・CEX/DEX・NFT・DeFi・セキュリティ等に加え、変化球の一般クイズも収録。
- 購入済みの本はITEMに残り、いつでも何度でも再挑戦可能。
- 各問題の初回正解時のみGとKNOWLEDGEを付与。
- 各本を全問初回正解するとBOOK COMPLETEボーナスGを付与。
- 同じ問題を繰り返してもGは無限に増えない仕様。
- 本の価格・問題数・1問報酬・コンプリート報酬は本ごとに自由設定できるため、今後タイトルや価格を変えた新刊を追加可能。
- 既存の「はじめてのWeb3」購入SAVEを新BOOKシステムへ移行。
- 既存SAVE、PLAYER CARD、写真アイコン、引継ぎコード、ウォーキング編などを維持。
