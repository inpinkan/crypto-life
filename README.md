## 確認方法
- アドレスポイズニング編完了の既存SAVE：CONTINUEでNFT編が始まります。
- 初めから進める場合：アドレスポイズニング編のCOMPLETE画面からNFT編へ進みます。
- NFT編完了後：SAVEし、LOG 020の頭出しから再プレイできます。
- 購入画面を確認する場合：ITEMのJourney NFT Center（JNC）から開きます。
- この配布フォルダーは元プロジェクトのコピーを更新したものです。元フォルダーは変更していません。
- 別フォルダーのfile://表示ではブラウザによりSAVEの保存領域が異なる場合があります。必要な場合は元ゲームの引継ぎコードを利用してください。同じ公開URLへ更新すると既存の保存領域を利用できます。
